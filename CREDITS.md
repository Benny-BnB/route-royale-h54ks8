# Crédits

## Images
- Les 14 illustrations (dossier assets/) et l'icône (dossier icons/) ont été dessinées par Claude Code pour ce projet, en SVG. Aucune photo, aucune image externe.
- Le tableau de Bruegel (stop 4) n'est pas intégré : un bouton ouvre la page Wikipédia dans le navigateur (https://en.wikipedia.org/wiki/The_Blind_Leading_the_Blind).

## Textes
- Les histoires, morales, questions, indices et gages viennent du cahier des charges V4 de Samy (annexe A), et le message final de l'annexe B.
- Sources des faits : voir l'annexe C du cahier des charges. Les blagues et mises en perspective sont du commentaire de l'auteur, pas des faits sourcés.

## Technique
- HTML, CSS et JavaScript simples, sans bibliothèque ni ressource externe chargée à l'exécution.
- Polices : celles du système de l'iPhone.
